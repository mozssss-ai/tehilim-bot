מי לא עוקב בחזרה

אינסטגרם לא נותן לבוטים את רשימות העוקבים, אבל נותן לך להוריד אותן. מעלים כאן את הקובץ, והרשימה מחושבת בטלפון שלך. הקובץ לא נשלח לשום מקום.

איך מורידים את הקובץ מאינסטגרם (פעם אחת, בערך 5 דקות)
  1. באינסטגרם: פרופיל ← ☰ ← מרכז החשבונות (Accounts Center).
  2. המידע וההרשאות שלך ← הורדת המידע שלך ← הורדה או העברה של מידע.
  3. לבחור את החשבון tehilim_kol_yom ← חלק מהמידע ← לסמן רק עוקבים ונעקבים (Followers and following).
  4. הורדה למכשיר ← טווח תאריכים: כל הזמן ← פורמט: JSON ← יצירת קבצים.
  5. אינסטגרם שולח התראה כשהקובץ מוכן (בדרך כלל תוך כמה דקות). מורידים את קובץ ה-ZIP ומעלים אותו כאן.
