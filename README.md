# בוט "תהילים כל יום" 📖

👉 **[מצב הבוט עכשיו – STATUS.md](STATUS.md)**

מעלה כל יום לאינסטגרם (@tehilim_kol_yom) ריל של הפרק היומי: תמונות הפרק, ואחריהן תמונת "גם אני בקבוצת" עם הקישור לקבוצת הוואטסאפ.

## איך הוא עובד
- **פרק אחד ביום, לפי הסדר.** בסוף הספר מתחיל מחזור חדש מפרק א'.
- **ימי חול:** העלאה בשעה שהבוט למד שהכי טובה (מתעדכן כל ראשון).
- **כל ריל עולה גם לסטורי**, עם מנגינת רקע שקטה (מקורית, בלי מילים) מתוך assets/music.
- **מי שכותב "תהילים" בתגובה** מקבל תגובה + הודעה פרטית עם הקישור לקבוצה (נבדק כל חצי שעה).
- **ערב שבת או חג:** העלאה מוקדמת, שעתיים לפני השקיעה.
- **שבת וחג:** אין העלאות. הפרק של השבת עולה כשעה אחרי צאת השבת, לפי זמני אשקלון ולוח ארץ ישראל.
- **כיתוב:** מספר הפרק והתאריך העברי מחושבים אוטומטית.
- **הרצה:** GitHub Actions מריץ את הבוט כל חצי שעה, והוא מחליט לבד אם הגיע הזמן להעלות.
- **מפתח הגישה לאינסטגרם** מתחדש אוטומטית כל שבוע.

## קבצים
| קובץ | מה יש בו |
|---|---|
| `config.json` | הגדרות: תאריך תחילת המחזור, שעת העלאה, כיתוב, קישור לקבוצה |
| `learn.json` | השעות שהבוט למד שעובדות הכי טוב (מתעדכן כל ראשון) |
| `images/` | תמונות הפרקים (`001_1.png`, `132_1.png`, `132_2.png` ...) |
| `assets/join_reel.png` | התמונה האחרונה בכל ריל, "גם אני בקבוצת" |
| `assets/music.mp3` | ניגון רקע. לא חובה: בלי הקובץ הריל עולה בלי מוזיקה |
| `state.json` | אילו פרקים כבר עלו (הבוט מעדכן לבד) |

## פעולות נפוצות
- **לשנות שעת העלאה:** לערוך את `post_time` ב-`config.json`.
- **להתחיל מחזור מתאריך אחר:** לערוך את `cycle_start` ולרוקן את `state.json` ל-`{"posted": []}`.
- **להעלות עכשיו ידנית:** Actions ← post daily chapter ← Run workflow. הבוט יעלה רק אם הפרק כבר אמור לעלות.
- **לבדוק את החיבור לאינסטגרם:** Actions ← test instagram connection ← Run workflow.
- **אם משהו נכשל:** GitHub שולח מייל אוטומטי. הפרק יעלה בהרצה הבאה, ואף פרק לא מדולג.

## Secrets נדרשים (Settings ← Secrets and variables ← Actions)
- `IG_TOKEN`: מפתח הגישה לאינסטגרם, מהגדרות האפליקציה באתר המפתחים של מטא.
- `GH_PAT`: מפתח GitHub עם הרשאת `repo`. משמש רק לחידוש האוטומטי של `IG_TOKEN`.
